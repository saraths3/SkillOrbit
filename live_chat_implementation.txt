================================================================================
           SKILLORBIT LIVE CHAT IMPLEMENTATION SUMMARY (CHEAT SHEET)
================================================================================

This file shows the EXACT, concise places where Live Chat was configured in this
SkillOrbit project. Compare this file with `live_chat_tutorial.txt` to see how 
theory turns into practice!

--------------------------------------------------------------------------------
1. `SkillOrbit/settings.py` (Configuration)
--------------------------------------------------------------------------------
• Installed Apps: Added `'daphne'` as Line #1, followed by `'chat'` and `'channels'`:
    INSTALLED_APPS = [
        'daphne',      # Top of INSTALLED_APPS (forces runserver to use ASGI)
        'chat',        # Our Chat Django App
        'skill',
        'core',
        'channels',    # Django Channels
        ...
    ]

• ASGI Pointer: Defined the ASGI application entry point:
    ASGI_APPLICATION = 'SkillOrbit.asgi.application'

• Channel Layer: Set in-memory messaging backend for local development:
    CHANNEL_LAYERS = {
        "default": {
            "BACKEND": "channels.layers.InMemoryChannelLayer",
        },
    }

--------------------------------------------------------------------------------
2. `SkillOrbit/asgi.py` (Protocol Router)
--------------------------------------------------------------------------------
• Wrapped WebSocket routes with `ProtocolTypeRouter` and `AuthMiddlewareStack`:
    application = ProtocolTypeRouter({
        "http": django_asgi_app,
        "websocket": AuthMiddlewareStack(
            URLRouter(chat.routing.websocket_urlpatterns)
        ),
    })

--------------------------------------------------------------------------------
3. `chat/routing.py` (WebSocket URLs)
--------------------------------------------------------------------------------
• Mapped URL pattern `ws/chat/<target_user_id>/` to `ChatConsumer`:
    websocket_urlpatterns = [
        re_path(r'ws/chat/(?P<target_user_id>\d+)/$', consumers.ChatConsumer.as_asgi()),
    ]

--------------------------------------------------------------------------------
4. `chat/consumers.py` (WebSocket Logic)
--------------------------------------------------------------------------------
• `ChatConsumer(AsyncWebsocketConsumer)` handles 3 main events:
    1. `connect()`   -> Authenticates user, creates room group name `chat_<user1>_<user2>`, joins group, accepts socket.
    2. `receive()`   -> Receives text from JS, saves to DB via `@database_sync_to_async`, broadcasts to room group.
    3. `disconnect()` -> Removes socket from room group on exit.

--------------------------------------------------------------------------------
5. `templates/chat/chat.html` (Frontend JS Client)
--------------------------------------------------------------------------------
• Connection: `chatSocket = new WebSocket('ws://' + host + '/ws/chat/' + targetUserId + '/')`
• Receive: `chatSocket.onmessage` appends incoming broadcast messages to chat box.
• Send: `chatSocket.send(JSON.stringify({"message": text}))` sends typed text on Enter/Submit.

--------------------------------------------------------------------------------
6. How To Run
--------------------------------------------------------------------------------
• Run: `python SkillOrbit/manage.py runserver`
  (Daphne ASGI boots automatically, enabling HTTP + real-time WebSockets instantly).
